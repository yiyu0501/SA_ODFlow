# UI_CHANGELOG_v14

## Summary

Polish release focused only on Template Center and Generate Document layout.

## Fixed / Added

- Template Center search field now works through GET query parameter `q`.
- Template Center category, format, and usage filters now work.
- Clear filter link resets back to the full template list.
- Category tabs preserve the active search/filter state.
- Generate Document stepper no longer has lines crossing through labels.
- Generate Document Step 1/2/3 shell now uses a safer responsive layout.

## Not Changed

- Homepage
- Dashboard
- File Library
- Settings page
- ODT / ODS generation backend
- Template registry logic
- Database schema
