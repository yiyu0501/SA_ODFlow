# ODFlow 7 分鐘簡報大綱

## 投影片 1：封面

- 作品名稱：ODFlow
- 一句話定位：學生社團 ODF 文件流與評鑑整理系統
- 副標：平時保存 ODF 原始檔，評鑑時輸出 PDF 評鑑上傳包

講述重點：
- 先讓評審知道這不是單純文件轉檔工具
- 這是一套把日常文件整理、ODF 保存、評鑑輸出串起來的流程系統

## 投影片 2：問題背景

- 學生社團平時文件分散在 Word、Excel、PDF、聊天紀錄與個人電腦
- 到評鑑前才開始臨時整理，常常找不到原始檔
- 最後只剩 PDF，後續不易維護與交接

講述重點：
- 強調這是社團日常行政與評鑑流程的真實痛點
- 說明評鑑壓力往往來自「平時沒整理」，不是「不會做 PDF」

## 投影片 3：使用者痛點

- 不知道哪些文件已完成
- 不知道哪些評鑑項目還缺資料
- 平時沒有穩定保存 ODF 原始檔的習慣
- 評鑑上傳和原始檔保存之間沒有整合流程

講述重點：
- 把痛點拆成「生成」「管理」「檢核」「輸出」四段
- 幫評審理解為什麼這不是單點工具，而是流程工具

## 投影片 4：ODFlow 解法

- Generate：建立五種核心社團文件
- Files：管理版本、狀態、ODT / PDF 匯出
- Dashboard：查看社團評鑑資料完整度
- Evaluation：輸出 PDF 評鑑上傳包與 ODF 原始檔備份 ZIP
- Templates：提供 22 個 ODT / ODS 範本

講述重點：
- 用頁面分工快速講清楚系統結構
- 說明這套流程的主軸是「平時累積，評鑑輸出」

## 投影片 5：系統流程

流程建議：
1. Settings 設定社團基本資料
2. Templates 或 Generate 建立文件
3. Files 保存版本與匯出 ODT / PDF
4. Dashboard 追蹤完整度
5. Evaluation 輸出評鑑 ZIP

講述重點：
- 這一頁可搭配流程圖
- 強調文件不是評鑑前臨時生成，而是平時就進入系統

## 投影片 6：ODF 應用重點

- 平時生成與保存 ODF 原始檔
- 評鑑對外輸出使用 PDF
- 範本庫降低學生從 Word / Excel 轉向 ODF 的門檻
- ODF 原始檔備份 ZIP 保留可持續維護的內容

講述重點：
- 說明為什麼這是 ODF 應用，而不是一般文件管理系統
- ODF 的價值在流程內，而不只是格式名稱

## 投影片 7：Demo 流程

- 建立或確認社團基本資料
- 建立示範資料
- Generate 建立會議紀錄或活動企劃書
- Files 匯出 ODT / PDF
- Dashboard 查看社團評鑑資料完整度
- Evaluation 匯出 PDF 評鑑上傳包與 ODF 備份 ZIP
- Templates 展示 22 個範本與核心範本建立文件

講述重點：
- 讓評審先知道等等 demo 要看什麼
- 順序要和實際操作影片一致

## 投影片 8：創新與實用性

- 不只產生會議紀錄，已支援五種核心社團文件
- 22 個 ODT / ODS 範本可做日常行政、活動與評鑑整理
- 核心範本可直接帶入 Generate 建立文件
- Dashboard 與 Evaluation 讓文件累積變成可檢查、可輸出的成果

講述重點：
- 創新點不是做複雜 AI，而是把 ODF、文件流、評鑑整理結合成可落地流程
- 實用性在於社團平時就能使用

## 投影片 9：AI 使用說明

- 開發過程有使用 AI 協助規劃、撰寫程式與整理文件
- 系統內目前使用 mock parser，不是真正串 OpenAI API
- 除會議紀錄外，其餘核心文件可直接用表單生成
- ODF / PDF / ZIP 輸出由程式規則產生

講述重點：
- 誠實說明 AI 範圍
- 避免讓評審誤以為作品價值完全依賴 LLM

## 投影片 10：未來推廣建議與結語

- 可擴充更多社團文件類型與範本
- 可依不同學校評鑑規則調整分類規則
- 未來可加入真正的 AI 文字整理，但保留人工確認與版本管理
- 結語：ODFlow 希望讓 ODF 成為學生社團日常文件流程的一部分

講述重點：
- 收尾要回到 ODF 推廣價值
- 強調這是一個可展示、可擴充、可落地的學生組作品
