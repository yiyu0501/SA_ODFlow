# 截圖清單

## 1. Home 首頁

- 截圖目的：讓評審第一眼理解作品定位
- 畫面重點：一句話介紹、核心流程、目前已完成功能
- 對應比賽說明用途：作品概覽頁、GitHub repo 首圖說明

## 2. Settings 社團基本資料

- 截圖目的：展示系統可設定展示資料與匯出預設值
- 畫面重點：學年度、校區、社團名稱、儲存按鈕
- 對應比賽說明用途：展示資料起點、說明 Evaluation 命名來源

## 3. 建立示範資料成功畫面

- 截圖目的：證明 demo 可快速建立展示資料
- 畫面重點：建立成功訊息、已建立的示範資料名稱
- 對應比賽說明用途：展示快速啟動能力

## 4. Generate 會議紀錄生成

- 截圖目的：展示文字整理成會議紀錄草稿的流程
- 畫面重點：輸入欄位、逐字稿內容、產生草稿結果
- 對應比賽說明用途：說明 mock parser 與文件生成入口

## 5. Files 文件庫

- 截圖目的：展示文件集中管理與版本管理
- 畫面重點：文件名稱、狀態、版本、評鑑分類
- 對應比賽說明用途：展示文件治理與保存流程

## 6. Files ODT/PDF 匯出下載

- 截圖目的：展示 ODF 原始檔與 PDF 匯出能力
- 畫面重點：產生 / 更新 ODT、產生 / 更新 PDF、下載按鈕
- 對應比賽說明用途：說明平時保存 ODF、評鑑使用 PDF

## 7. Dashboard 社團評鑑資料完整度

- 截圖目的：展示完整度儀表板
- 畫面重點：整體社團評鑑資料完整度、七大項目完成率、缺漏提醒
- 對應比賽說明用途：展示評鑑前的管理價值

## 8. Evaluation 缺漏檢核

- 截圖目的：展示七大評鑑項目缺漏文件檢查
- 畫面重點：評鑑分類、缺漏文件、對應文件列表
- 對應比賽說明用途：展示不是只會輸出 ZIP，還能先檢查資料

## 9. Evaluation PDF 評鑑上傳包匯出

- 截圖目的：展示一鍵輸出正式評鑑資料包
- 畫面重點：學年度 / 校區 / 社團名稱、產生按鈕、下載按鈕、摘要
- 對應比賽說明用途：展示最終提交成果

## 10. Templates ODF 範本庫

- 截圖目的：展示 ODF 範本庫與 22 個範本的方向
- 畫面重點：三大分類、範本名稱、產生範本、下載範本
- 對應比賽說明用途：強化 ODF 競賽定位與推廣價值

## 11. 解壓縮後的七大評鑑資料夾結構

- 截圖目的：展示匯出的 ZIP 符合評鑑資料夾整理需求
- 畫面重點：最上層命名、七大分類資料夾、索引表與未輸出文件清單
- 對應比賽說明用途：證明系統不只生成文件，也能整理提交格式
