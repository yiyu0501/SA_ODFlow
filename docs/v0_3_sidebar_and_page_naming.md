# ODFlow v0.3 側邊欄與頁面命名規劃

## 命名原則

1. 全面使用中文
2. 名稱要讓非技術使用者一看就懂
3. 名稱要對應實際用途，不用過短的抽象詞
4. Projects 頁要明確弱化，不可誤導成目前主功能

## 建議側邊欄命名

1. 首頁
2. 儀表板
3. 生成文件
4. 檔案庫
5. 專案
6. 社團評鑑
7. 空白範本
8. 社團設定

## 各頁面用途與命名理由

### 首頁

用途：
說明 ODFlow 的核心流程、作品定位與主要入口。

命名理由：
「首頁」比 Home 更符合一般使用者習慣，也適合作為展示起點。

### 儀表板

用途：
查看社團評鑑資料完整度、缺漏重點、最近文件與下一步建議。

命名理由：
「儀表板」能直接傳達這是一個總覽頁，不只是資料列表。

### 生成文件

用途：
建立五種核心文件，包含會議紀錄、活動企劃書、活動成果報告、活動檢討會紀錄、年度計畫。

命名理由：
目前這頁不只是 AI 生成，也包含表單式生成，所以用「生成文件」比 Generate 更完整。

### 檔案庫

用途：
管理文件清單、版本、狀態、ODF 原始檔與 PDF 匯出。

命名理由：
「檔案庫」比 Files 更貼近一般人的理解，也能傳達這裡是集中管理區。

### 專案

用途：
目前僅保留未來擴充位置，不是 v0.3 核心頁面。

命名理由：
仍保留「專案」這個名稱，因為未來可能發展成活動或年度工作管理，但目前頁面必須清楚標示「未來擴充」。

### 社團評鑑

用途：
查看七大項目檢核、缺漏文件，並輸出 PDF 評鑑上傳包與 ODF 原始檔備份 ZIP。

命名理由：
Evaluation 對一般使用者不夠直覺，「社團評鑑」能直接說明這頁和學校評鑑整理有關。

### 空白範本

用途：
下載 22 個 ODT / ODS 空白範本，並從 5 個核心範本進入建立文件流程。

命名理由：
這一頁的第一層心智模型應是「範本庫」，而且要明確區分它不是 Files，也不是 Generate。
用「空白範本」能幫助使用者理解這裡主要提供可直接下載的 ODF 樣板。

### 社團設定

用途：
設定學年度、校區、社團名稱、負責人與建立示範資料。

命名理由：
「社團設定」比 Settings 更清楚，也能說明這裡不是系統設定，而是社團基本資料設定。

## 為什麼不要用英文頁名

1. 作品主要展示對象是中文使用者與評審
2. 英文頁名會增加首次理解成本
3. 中文命名更容易和校園行政文件情境對齊

## 為什麼不要短到看不懂

例如單用「生成」「評鑑」「範本」，雖然簡短，但不夠完整。
v0.3 追求的是可理解度，不是極簡詞彙。

## Projects / 專案頁的建議標示

建議頁面中直接標示：

1. 目前為未來擴充
2. 現階段核心流程請優先使用生成文件、檔案庫、儀表板、社團評鑑與空白範本

這樣可避免評審誤以為專案管理是目前主產品，但實際上內容還沒完成。
