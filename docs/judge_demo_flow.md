# 5 分鐘評審展示流程

## 1. 30 秒：痛點與作品定位

- 說明學生社團平時文件分散，評鑑前才臨時整理
- 說明 ODFlow 的定位是學生社團 ODF 文件流與評鑑整理系統
- 強調平時保存 ODF 原始檔，評鑑時輸出 PDF 評鑑上傳包

## 2. 40 秒：Settings 與示範資料

- 進入 Settings
- 展示學年度、校區、社團名稱
- 點擊建立示範資料
- 說明這些資料會直接影響後續匯出命名與展示內容

## 3. 60 秒：Generate 產生會議紀錄

- 輸入會議日期、名稱、類型與逐字稿
- 點擊產生會議紀錄草稿
- 說明目前使用 mock parser，尚未串 OpenAI API
- 強調這是最小可展示、可替換的生成流程

## 4. 60 秒：Files 匯出 ODT / PDF

- 進入 Files
- 展示文件列表、狀態、版本
- 產生或更新 ODT
- 產生或更新 PDF
- 說明 ODF 原始檔保存與 PDF 對外使用的分工

## 5. 60 秒：Dashboard / Evaluation 看完整度與缺漏

- 在 Dashboard 展示整體社團評鑑資料完整度
- 說明七大項目完成率
- 切到 Evaluation 展示缺漏文件檢核
- 說明系統不只是輸出，還能先幫忙檢查缺漏

## 6. 40 秒：一鍵輸出評鑑 ZIP 與 ODF 備份 ZIP

- 在 Evaluation 輸入或確認學年度、校區、社團名稱
- 產生 PDF 評鑑上傳包
- 再產生 ODF 原始檔備份 ZIP
- 強調目前是本機 ZIP 下載，不是雲端自動上傳

## 7. 30 秒：Templates 範本庫與 ODF 推廣價值

- 進入 Templates
- 展示目前支援 22 個 ODT / ODS 範本
- 說明三大分類：日常行政型、專案活動型、社團評鑑型
- 強調這能降低從 Word / Excel 轉向 ODF 的門檻

## 8. 20 秒：總結

- ODFlow 把 ODF 原始檔保存、文件管理、評鑑整理串成一個流程
- 平時就能用，評鑑前不用重做一次
- 作品目前是穩定可展示的 ODF 競賽展示版 MVP
