# UI_SPEC_v15_ODFlow_settings_center

## 修正範圍

本版只修「社團設定頁」。首頁、儀表板、空白範本、生成文件、檔案庫不動。

## 設計方向

社團設定頁改成類似 Google / Microsoft / Amazon 帳號中心的條列式設定，而不是 dashboard 格子。

版型：

- 左側設定分類導覽：260px
- 右側設定內容：1fr
- 每一列設定項包含：
  - 設定名稱
  - 說明文字
  - 目前狀態 / 目前值
  - 右側操作按鈕

## 分類

保留六個分類：

1. 社團與帳號
2. 成員與權限
3. 文件與輸出
4. 通知
5. 資料與備份
6. 系統資訊

移除：

- 評鑑與流程：由系統預設，不開放社團調整
- 外觀與輔助：目前維持統一視覺，不開放設定

## 社團與帳號

- 社團名稱
- 學年度
- 校區
- 社團類型
- 負責人
- 指導老師

## 成員與權限

- 管理員
- 幹部成員
- 可編輯文件的人
- 可下載檔案的人
- 權限狀態

目前為 UI 展示，尚未接正式登入權限。

## 文件與輸出

- 文件命名規則
- 命名範例
- 歸檔規則
- 預設輸出格式
- PDF 匯出
- 檔案庫分類方式

此區保留「文件命名規則」，方便符合不同學校對檔名格式的要求。

## 通知

- 缺件提醒
- 文件待確認提醒
- 最近文件提醒
- 通知中心

對應右上角鈴鐺入口。

## 資料與備份

- 匯出全部文件
- 匯出檔案庫清單
- 資料儲存位置
- 備份狀態
- 清除展示資料

## 系統資訊

- ODFlow 版本
- 支援格式
- 目前環境
- 服務狀態
- GitHub Repository

## 不做的事

本版只做 UI 與資訊架構，不接實際編輯、匯出、清除資料或權限系統。
