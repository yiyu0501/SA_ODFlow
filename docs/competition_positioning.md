# ODFlow 比賽定位說明

## 1. 作品名稱

ODFlow

## 2. 作品定位

學生社團 ODF 文件流與評鑑整理系統

## 3. 對應 ODF 競賽學生組方向

- ODF 應用工具
- ODF 文件範本與輸出流程
- ODF 推廣與保存價值

## 4. 解決痛點

- 社團文件分散，平時沒有固定整理流程
- 評鑑前才開始臨時整理，補件與分類成本高
- ODF 原始檔常常沒有被持續保存，只剩 PDF
- PDF 上傳需求與 ODF 長期保存需求之間缺乏整合流程

## 5. 創新點

- 平時就生成與保存 ODF 原始檔
- 年底或評鑑前一鍵輸出 PDF 評鑑上傳包
- 依七大評鑑項目自動分類
- 用儀表板顯示社團評鑑資料完整度、缺漏文件與補件建議
- 提供學生社團常用的 ODT / ODS 範本庫
- 已支援會議紀錄、開會通知、會議議程、活動企劃書、活動成果報告、活動檢討會紀錄、年度計畫七種核心文件生成
- 核心文件可輸出較正式的 ODT / PDF，強化列印、評鑑提交與日常使用情境

## 5.1 本次介面升級如何回應評審需求

- 介面與側邊欄改為中文命名，降低第一次觀看的理解成本
- 首頁改成產品導覽頁，讓評審更容易看懂從建立文件到輸出評鑑 ZIP 的完整流程
- 空白範本頁明確支援直接下載空白範本，不再像工程展示頁
- 儀表板與社團評鑑頁更直接呈現哪些文件已可用、哪些還缺，讓作品更像日常社團工具
- 更明確強調 ODF 原始檔保存與 PDF 評鑑上傳包的分工，強化 ODF 推廣價值

## 6. 空白範本如何強化 ODF 競賽定位

- 提供學生社團常用 ODF 範本，包含日常行政、活動專案、社團評鑑、財務與清冊四類
- 降低學生從 Word / Excel 轉向 ODF 的門檻
- 讓核心範本不只是下載空白檔，也能直接帶入「生成文件」建立正式文件
- 平時保留 ODF 原始檔，評鑑時再輸出 PDF 評鑑上傳包
- 讓 ODF 不只是轉檔，而是真正進入社團行政與活動流程
- 透過較正式的版面、表格與章節設計，讓 ODF 文件本身就具備提交與列印價值，不只是工程測試輸出

## 7. 多文件生成如何強化作品價值

- 不再只支援會議紀錄，而是擴展到學生社團日常最常用的七種核心文件
- 讓開會通知、會議議程、活動企劃書、活動成果報告、活動檢討會紀錄、年度計畫都能進入同一套 ODF / PDF / ZIP 流程
- 讓儀表板與社團評鑑頁的完整度計算，能直接建立在日常文件累積上，而不是評鑑前臨時補件

## 8. AI 使用說明

- 目前 MVP 使用 mock parser
- 尚未串 OpenAI API
- 尚未支援音檔轉文字與 Google Drive API
- 除會議紀錄外，其餘核心文件可用表單式流程直接生成，不依賴 OpenAI
- 不依賴 OpenAI，也能完成 ODF 原始檔產生、PDF 匯出、PDF 評鑑上傳包與 ODF 原始檔備份 ZIP 流程
- ODF / PDF / ZIP 流程仍由系統規則產生，不交由 AI 任意決定
- 目前是本機 ZIP 下載，不是雲端自動上傳
