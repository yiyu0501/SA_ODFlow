# ODFlow 比賽定位說明

## 1. 作品名稱

ODFlow

## 2. 作品定位

學生社團 ODF 文件流與評鑑整理系統

## 3. 對應 ODF 競賽學生組方向

- ODF 應用工具
- ODF 文件範本與輸出流程
- ODF 推廣與保存價值

## 4. 解決痛點

- 社團文件分散，平時沒有固定整理流程
- 評鑑前才開始臨時整理，補件與分類成本高
- ODF 原始檔常常沒有被持續保存，只剩 PDF
- PDF 上傳需求與 ODF 長期保存需求之間缺乏整合流程

## 5. 創新點

- 平時就生成與保存 ODF 原始檔
- 年底或評鑑前一鍵輸出 PDF 評鑑上傳包
- 依七大評鑑項目自動分類
- 用 Dashboard 顯示資料完整度、缺漏文件與補件建議
- 提供學生社團常用的 ODT / ODS 範本庫
- 已支援會議紀錄、活動企劃書、活動成果報告、活動檢討會紀錄、年度計畫五種核心文件生成

## 6. Templates 如何強化 ODF 競賽定位

- 提供學生社團常用 ODF 範本，包含日常行政、專案活動、社團評鑑三大類
- 降低學生從 Word / Excel 轉向 ODF 的門檻
- 讓核心範本不只是下載空白檔，也能直接帶入 Generate 建立正式文件
- 平時保留 ODF 原始檔，評鑑時再輸出 PDF
- 讓 ODF 不只是轉檔，而是真正進入社團行政與活動流程

## 7. AI 使用說明

- 目前 MVP 使用 mock parser
- 尚未串 OpenAI API
- 除會議紀錄外，其餘核心文件可用表單式流程直接生成，不依賴 OpenAI
- 若未來導入 AI，會限定在文字整理與會議紀錄草稿生成
- ODF / PDF / ZIP 流程仍由系統規則產生，不交由 AI 任意決定
