# AI Usage Statement

## 目前狀態

ODFlow 目前 MVP 沒有直接呼叫 OpenAI API。

現在系統中的「文字／逐字稿轉會議紀錄」流程，使用的是 `ai/mock_parser.py`，目的是提供可展示、可測試、可替換的最小流程，而不是宣稱已具備真正大型語言模型能力。

## 目前 AI 使用範圍

- 會議文字整理成會議紀錄草稿
- 根據簡單規則填入基本欄位
- 維持可編輯的草稿輸出

## 目前不包含

- OpenAI API 串接
- 音檔語音轉文字
- 自動評分預測
- 雲端 AI 文件理解流程

## 未來若導入 AI 的原則

- 只限定在文字整理與會議紀錄草稿生成
- 需額外補上金鑰管理、錯誤處理、成本控制與輸出驗證
- ODF / PDF / ZIP 匯出流程仍由系統規則與既有 generator 控制，不交給 AI 決定
