# ODFlow 操作影片腳本

## 影片定位

- 建議片長：3 至 5 分鐘
- 影片目的：讓評審快速理解 ODFlow 的操作流程與 ODF 價值
- 影片節奏：每段控制在 20 至 40 秒，避免停留過久

## 1. 首頁介紹

畫面操作：
- 開啟首頁
- 停留在專案名稱、作品定位、功能導覽區塊

旁白建議：
- 這是 ODFlow，一套學生社團 ODF 文件流與評鑑整理系統。
- 它的核心是讓社團平時保存 ODF 原始檔，評鑑時再輸出 PDF 評鑑上傳包。

截圖或錄影重點：
- 作品名稱
- 一句話定位
- 系統頁面入口

## 2. Settings 設定社團基本資料

畫面操作：
- 進入 Settings 頁
- 輸入學年度、校區、社團名稱
- 視情況帶到社團類型、負責人姓名、指導老師欄位

旁白建議：
- Settings 用來設定社團基本資料，這些內容會直接影響後續文件命名與評鑑 ZIP 命名。

截圖或錄影重點：
- 學年度
- 校區
- 社團名稱

## 3. 建立示範資料

畫面操作：
- 點擊「建立示範資料」
- 顯示成功訊息或建立後的狀態

旁白建議：
- 系統可以快速建立示範資料，包含會議紀錄、活動企劃書、活動成果報告、活動檢討會紀錄與年度計畫，方便展示後續流程。

截圖或錄影重點：
- 成功訊息
- 建立後可用於 Dashboard 與 Evaluation 的效果

## 4. Generate 產生多種文件

畫面操作：
- 進入 Generate 頁
- 展示文件類型下拉選單
- 先選「會議紀錄」，貼上一小段逐字稿或摘要，產生草稿
- 再快速切到「活動企劃書」或「年度計畫」，展示表單式生成

旁白建議：
- Generate 已支援五種核心社團文件。
- 會議紀錄可以用文字或逐字稿先產生草稿，其餘文件則可以直接用表單建立。
- 這代表系統不只支援會議紀錄，而是日常社團文件流程。

截圖或錄影重點：
- 五種文件類型選單
- mock parser 產生會議紀錄草稿
- 表單式生成其他文件

## 5. Files 匯出 ODT / PDF

畫面操作：
- 進入 Files 頁
- 展示文件列表中的不同 document type
- 選一份文件
- 點擊「產生 / 更新 ODT」
- 點擊「產生 / 更新 PDF」

旁白建議：
- Files 頁負責管理文件、版本與狀態。
- 這裡可以把內容匯出成 ODF 原始檔，也能輸出對外提交使用的 PDF。

截圖或錄影重點：
- 文件類型欄位
- 版本與狀態
- ODT / PDF 按鈕

## 6. Dashboard 查看社團評鑑資料完整度

畫面操作：
- 進入 Dashboard 頁
- 展示整體社團評鑑資料完整度
- 顯示七大評鑑項目完成率與缺漏提醒

旁白建議：
- Dashboard 讓社團知道哪些評鑑項目已經完成，哪些還在進行中，哪些還缺文件。
- 這讓資料整理從臨時補件，變成平時就能追蹤的流程。

截圖或錄影重點：
- 整體完整度
- 七大項目完成率
- 缺漏文件提醒

## 7. Evaluation 輸出 PDF 評鑑上傳包與 ODF 原始檔備份 ZIP

畫面操作：
- 進入 Evaluation 頁
- 顯示檢核表與匯出區
- 產生 PDF 評鑑上傳包
- 再產生 ODF 原始檔備份 ZIP

旁白建議：
- Evaluation 會依七大評鑑分類整理文件。
- 正式版或已歸檔文件可進入 PDF 評鑑上傳包。
- 同時也能另外輸出 ODF 原始檔備份 ZIP，保留可持續編修的原始內容。

截圖或錄影重點：
- 匯出按鈕
- ZIP 檔名
- 輸出摘要

## 8. Templates 產生 ODT / ODS 範本

畫面操作：
- 進入 Templates 頁
- 展示三大分類
- 點一個範本產生與下載
- 點一個核心 ODT 範本的「使用此範本建立文件」

旁白建議：
- Templates 提供 22 個 ODT / ODS 範本，分成日常行政、專案活動、社團評鑑三大類。
- 其中 5 個核心 ODT 範本不只可下載空白檔，也可直接帶入 Generate 建立正式文件。

截圖或錄影重點：
- 22 個範本庫
- 核心範本建立文件
- ODT / ODS 下載

## 9. 收尾說明

畫面操作：
- 回到首頁或停留在 Templates / Evaluation 的代表畫面

旁白建議：
- ODFlow 的重點不是只幫社團做 PDF，而是把 ODF 原始檔保存、日常文件生成、完整度追蹤與評鑑輸出串成同一套流程。
- 這讓 ODF 不只是檔案格式，而是能真正進入學生社團日常行政的工具。

截圖或錄影重點：
- 作品名稱
- ODF 原始檔與 PDF 評鑑上傳包兩種價值
