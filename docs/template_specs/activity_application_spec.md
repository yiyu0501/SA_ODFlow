# ODFlow 範本規格書：活動申請表

## 一、範本基本資料

範本名稱：活動申請表
常見別名：社團活動申請表、活動辦理申請表、活動核准申請表
template key：activity_application
格式：ODT
分類：專案活動型
重要性：最高
是否保留：保留，核心範本
是否支援空白範本下載：支援
是否支援使用此範本建立文件：支援

本範本以臺北市立大學社團活動申請表格式為基準，用於協助學生社團在活動辦理前填寫並產生可送交學校行政流程使用的活動申請表。

本範本與活動企畫書不同：

* 活動企畫書：完整說明活動內容、流程、分工、預算與附件。
* 活動申請表：送學校審核、登記、核准與行政簽核用的一頁式行政表單。

活動申請表 v1 的核心原則是：

1. 以臺北市立大學既有社團活動申請表為基準。
2. 必須使用 A4 橫式一頁。
3. 不得使用 A4 直式。
4. 視覺上接近學校原表單。
5. 底層重新製作乾淨 ODT，不直接沿用原始 DOC。
6. 社團只填社團應填欄位。
7. 學校行政欄位保留空白，不由 ODFlow 填入。
8. 長文字採摘要填入，不讓表格撐爆。
9. 勾選框以文字符號「□ / ■」處理。
10. 文件打開後應像正式活動申請表，而不是範本說明頁。

---

## 二、文件標題

正式文件標題應照學校表單格式。

標題格式：

臺北市立大學　社團活動申請表

標題置中顯示，位於 A4 橫式頁面上方。

標題右側或下方應保留注意事項：

* 請於活動二週前完成申請並隨表附活動企畫書
* 申請校內場地，請增附場地申請表

注意事項應保留於第一頁，不得被擠到第二頁。

---

## 三、文件版面原則

活動申請表是固定一頁的行政表單，不是可自由延伸的文件。

### 1. 紙張與頁面

必須設定：

* 紙張：A4
* 方向：橫式
* 頁數：固定一頁
* 上下頁邊距：約 0.8 至 1.0 cm
* 左右頁邊距：約 0.8 至 1.0 cm
* 主要字型：標楷體

禁止設定：

* A4 直式
* 自動延伸成第二頁
* 因內容過長而改變頁面方向
* 因內容過長而擠壓行政簽核區

### 2. 字級建議

因本表單是 A4 橫式一頁，欄位多、表格密，字級可比一般文件小。

建議設定：

* 文件標題：標楷體，18 至 22 pt，粗體，置中
* 注意事項：標楷體，8.5 至 10 pt
* 欄位標籤：標楷體，10 至 11 pt
* 一般填寫文字：標楷體，10 至 11 pt
* 活動性質說明：標楷體，8.5 至 9.5 pt
* 行政簽核區：標楷體，10 至 11 pt
* 最低可讀字級：9 pt

注意：repo 不應放入字型檔。ODT 可指定使用標楷體，實際顯示依使用者電腦或轉檔環境是否具備該字型而定。

---

## 四、實作方式

本範本不得直接修改學校原始 DOC 作為主要實作方式。

原因：

1. 原始 DOC 可能包含大量合併儲存格。
2. 任一欄位文字增加都可能影響整張表格。
3. 表格容易因文字過多而撐開。
4. 原始 DOC 轉檔時可能出現註記或頁尾內容跑到第二頁的問題。
5. 後續維護困難。
6. 程式自動填入時容易造成版面破裂。

ODFlow 應重新製作一份乾淨 ODT 版型。

實作原則：

1. 使用乾淨 ODT 重新建立表格。
2. 外觀盡量接近學校原始活動申請表。
3. 必須使用 A4 橫式。
4. 使用固定欄寬與固定區塊高度。
5. 使用 placeholder 填入資料。
6. 嚴格維持一頁。
7. 不允許表格因文字過長自動延伸成第二頁。
8. 行政簽核欄位不放 placeholder，不填「無」，保持空白。
9. 「使用種類與額度由課外活動組填寫」註記必須留在第一頁內，不得跑到第二頁。

---

## 五、版面區塊

活動申請表 v1 建議拆成六大區塊實作：

1. 表頭區
2. 基本資料區
3. 評鑑與活動性質區
4. 宗旨與活動內容區
5. 申請人與經費區
6. 行政簽核保留區

這六區必須共同組成一張 A4 橫式一頁表單。

---

## 六、表頭區

表頭區包含：

1. 文件標題
2. 申請注意事項
3. 表單代碼或附件文字，若需要保留

格式：

臺北市立大學　社團活動申請表

注意事項：

* 請於活動二週前完成申請並隨表附活動企畫書
* 申請校內場地，請增附場地申請表

若原表右上角有「14-6」與「附件二」等文字，應視版面需求保留在右上角，但不得讓它們造成第二頁。

表頭區不可過高，避免壓縮下方表格。

---

## 七、基本資料區

基本資料區為社團主要填寫區之一。

應包含以下欄位：

| 欄位     | 是否由 ODFlow 填寫 |
| ------ | ------------- |
| 活動名稱   | 是             |
| 活動時間，起 | 是             |
| 活動時間，止 | 是             |
| 活動地點   | 是             |
| 申請日期   | 是             |
| 主辦社團   | 是             |
| 參加人數   | 是             |
| 社長     | 是             |
| 社長電話   | 是             |
| 社團指導老師 | 是             |
| 指導老師電話 | 是             |

### 1. 活動名稱

欄位名稱：

活動名稱

版面規則：

1. 最多 2 行。
2. 建議 30 字內。
3. 31 至 40 字可縮小字體。
4. 超過 40 字應提醒使用者縮短。
5. 不得因活動名稱過長而撐開表格。
6. 不得因此讓文件變成第二頁。

---

### 2. 活動時間

欄位名稱：

活動時間

應拆成起訖時間。

格式：

{{start_year}} 年 {{start_month}} 月 {{start_day}} 日 {{start_hour}} 時 {{start_minute}} 分 起
{{end_year}} 年 {{end_month}} 月 {{end_day}} 日 {{end_hour}} 時 {{end_minute}} 分 止

說明：

1. 使用者應輸入開始日期時間與結束日期時間。
2. 系統可協助拆成表單需要的年月日時分。
3. 表單輸出時應盡量接近學校原格式。

---

### 3. 活動地點

欄位名稱：

活動地點

版面規則：

1. 最多 2 行。
2. 建議 30 字內。
3. 超過時可縮小字體。
4. 仍放不下時提醒使用者縮短。
5. 本表單不處理多地點詳細說明，完整內容應放活動企畫書。
6. 不得因活動地點過長而撐開表格。

---

### 4. 申請日期

欄位名稱：

申請日期

格式：

{{apply_year}} 年 {{apply_month}} 月 {{apply_day}} 日

說明：

1. 系統可預設為今日日期。
2. 使用者應可自行修改。
3. 申請日期不一定等於活動日期。

---

### 5. 主辦社團

欄位名稱：

主辦社團

格式：

{{club_name}}

或：

臺北市立大學 {{club_name}}

版面規則：

1. 建議 20 字內。
2. 可縮小字體。
3. 不得因主辦社團名稱過長而撐開表格。

---

### 6. 參加人數

欄位名稱：

參加人數

格式：

{{participant_count}} 人

應只填數字與「人」。

---

### 7. 社長與指導老師

欄位名稱：

社長
社團指導老師
電話

說明：

1. 社長姓名與電話由社團填寫。
2. 社團指導老師姓名與電話由社團填寫。
3. 若無指導老師電話，可留白或由使用者填「無」。

---

## 八、評鑑與活動性質區

此區包含前年社團評鑑與活動性質勾選。

---

### 1. 前年社團評鑑

欄位名稱：

前年社團評鑑

選項：

* 特優
* 優等
* 甲等
* 乙等

輸出格式：

前年社團評鑑：特優□　優等□　甲等□　乙等□

若選擇優等：

前年社團評鑑：特優□　優等■　甲等□　乙等□

規則：

1. 勾選框使用文字符號。
2. 未選為「□」。
3. 已選為「■」。
4. 前年社團評鑑為單選。
5. 若使用者不知道或不想填，可全部保持未勾選。
6. 不新增「無」選項，避免偏離學校表單。

---

### 2. 活動性質

欄位名稱：

活動性質

學校表單文字應保留：

競賽或運動性活動需自行聘請具證照之護理師或防護員

活動性質選項應照學校表單保留：

* 幹訓或營隊：具學習目的者。
* 學術活動：講演、大型學術、研討座談、展覽、比賽、研習、成果展等。
* 刊物出版：週刊、月刊、校刊。
* 康樂活動：校內外演奏會、出國演出、參加或主辦校際性比賽。
* 社會服務活動：含平時與寒暑假期間。
* 發展社團特色活動。
* 其他符合社團宗旨之綜合性活動。
* 學校委辦或代表學校之活動

輸出格式：

□ 幹訓或營隊：具學習目的者。
□ 學術活動：講演、大型學術、研討座談、展覽、比賽、研習、成果展等。
□ 刊物出版：週刊、月刊、校刊。
□ 康樂活動：校內外演奏會、出國演出、參加或主辦校際性比賽。
□ 社會服務活動：含平時與寒暑假期間。
□ 發展社團特色活動。
□ 其他符合社團宗旨之綜合性活動。
□ 學校委辦或代表學校之活動

規則：

1. 勾選框使用「□ / ■」。
2. 活動性質可複選。
3. UI 應提醒使用者通常選一個主要性質即可。
4. 活動性質區字級可縮小至 8.5 至 9.5 pt。
5. 不應自行新增、刪除或改寫學校表單的活動性質選項。

---

## 九、宗旨與活動內容區

此區包含：

1. 宗旨
2. 活動內容或講題

這兩個欄位最容易因文字過多導致表格破版，因此必須採摘要填入。

---

### 1. 宗旨

欄位名稱：

宗旨

用途：

簡短說明活動目的。

字數限制：

1. 建議 60 字內。
2. 可縮小字體，最低不低於 9 pt。
3. 超過限制時，UI 應提醒使用者改成摘要。
4. 不應自動硬塞長文。
5. 完整宗旨與詳細說明應放在活動企畫書中。

輸出欄位：

宗旨：{{purpose_summary}}

---

### 2. 活動內容或講題

欄位名稱：

活動內容或講題

用途：

簡短說明本次活動內容、講題或核心活動安排。

字數限制：

1. 建議 80 字內。
2. 可縮小字體，最低不低於 9 pt。
3. 超過限制時，UI 應提醒使用者改成摘要。
4. 不應自動硬塞長文。
5. 完整活動內容應放在活動企畫書中。

輸出欄位：

活動內容或講題：{{content_summary}}

---

## 十、申請人與經費區

此區包含活動申請人資料、活動費申請補助、自籌經費與合計。

---

### 1. 活動申請人

欄位名稱：

活動申請人

應包含：

姓名：{{applicant_name}}
系別：{{applicant_department}}
班別：{{applicant_class}}
手機：{{applicant_phone}}

規則：

1. 申請人資料由社團填寫。
2. 申請人欄位不應縮到難以閱讀。
3. 若欄位過長，應提醒使用者縮短或確認格式。

---

### 2. 活動費申請補助

欄位名稱：

活動費申請補助

格式：

{{subsidy_amount}} 元

規則：

1. 由社團填寫欲申請補助金額。
2. 應為數字。
3. 若無申請補助，可填 0。

---

### 3. 活動費自籌經費

欄位名稱：

活動費自籌經費

格式：

{{self_funded_amount}} 元

規則：

1. 由社團填寫自籌經費。
2. 應為數字。
3. 若無自籌，可填 0。

---

### 4. 合計

欄位名稱：

合計

計算方式：

合計 = 活動費申請補助 + 活動費自籌經費

格式：

{{total_amount}} 元

規則：

1. 優先由 ODFlow 系統後台自動計算。
2. ODT 文件只呈現計算完成的結果。
3. 不要求 ODT 文件本身內建公式。
4. 若計算功能實作成本過高，可暫時降級為手填，但規格保留自動計算方向。

---

## 十一、學校行政保留欄位

以下欄位不由 ODFlow 填寫，應保留空白。

---

### 1. 課外活動組欄位

不填欄位：

* 本次使用種類
* 一般補助
* 專案補助
* 額度
* 已使用額度，含本次
* 尚餘額度

理由：

學校表單已註明「使用種類與額度由課外活動組填寫」。因此，ODFlow 不應替社團填入這些欄位。

版面規則：

1. 保留原欄位。
2. 不放 placeholder。
3. 不填「無」。
4. 不自動勾選一般補助或專案補助。
5. 讓課外活動組行政人員後續填寫。
6. 「使用種類與額度由課外活動組填寫」註記必須在第一頁內。

---

### 2. 行政簽核欄位

以下欄位完全保留空白：

* 承辦人
* 單位主管
* 組長
* 學務長
* 會辦單位：總務處
* 會辦單位：會計室
* 校長

版面規則：

1. 保留固定高度空白格。
2. 不填「無」。
3. 不放 placeholder。
4. 不放系統產生資料。
5. 不應因其他欄位文字過長而壓縮行政簽核區。

---

## 十二、一頁限制與長文字處理

活動申請表必須維持 A4 橫式一頁。

### 1. 一頁限制

規則：

1. 輸出文件不得自動變成兩頁。
2. 表格不得因文字過多而撐高。
3. 區塊高度應固定。
4. 行政簽核區不得被擠壓。
5. 右上角注意事項與表單代碼不得被擠出頁面。
6. 「使用種類與額度由課外活動組填寫」註記不得被擠到第二頁。
7. 若內容超出可容納範圍，應在生成前提醒使用者縮短。

---

### 2. 長文字處理順序

文字超出時，依以下順序處理：

1. 優先縮小字體。
2. 最低字級不低於 9 pt。
3. 允許活動名稱、活動地點最多 2 行。
4. 宗旨與活動內容只填摘要。
5. 若仍超出，阻止輸出並提示使用者縮短。
6. 不得硬塞長文導致表格爆版。
7. 不得自動改成第二頁。
8. 不得改成直式。

---

### 3. 欄位字數建議

| 欄位      |         建議限制 | 處理方式               |
| ------- | -----------: | ------------------ |
| 活動名稱    | 30 字內，最多 2 行 | 31 至 40 字縮字，超過提醒縮短 |
| 活動地點    | 30 字內，最多 2 行 | 超過提醒改寫             |
| 主辦社團    |        20 字內 | 超過可縮字              |
| 宗旨      |        60 字內 | 超過提醒填摘要            |
| 活動內容或講題 |        80 字內 | 超過提醒填摘要            |
| 活動申請人資料 |         正常填寫 | 不縮到難以閱讀            |
| 經費欄位    |           數字 | 不放說明文字             |

---

## 十三、勾選框實作規則

本範本所有勾選框一律使用文字符號，不使用圖片、不插入形狀。

規則：

* 未勾選：□
* 已勾選：■

原因：

1. 減少 ODT 版面跑掉風險。
2. 避免圖片或形狀在不同環境中錯位。
3. 便於程式替換。
4. 輸出 PDF 時較穩定。
5. 便於未來測試比對文字內容。

---

## 十四、空白範本下載要求

下載的空白 ODT 應是正式活動申請表版型，並以臺北市立大學社團活動申請表為基準。

* A4
* 橫式
* 一頁
* 固定表格版面

空白範本應至少包含：

1. 表頭區
2. 注意事項
3. 活動名稱
4. 活動時間
5. 活動地點
6. 申請日期
7. 主辦社團
8. 參加人數
9. 社長與電話
10. 社團指導老師與電話
11. 前年社團評鑑
12. 活動性質
13. 宗旨
14. 活動內容或講題
15. 活動申請人
16. 活動費申請補助
17. 活動費自籌經費
18. 合計
19. 本次使用種類、額度、已使用額度、尚餘額度
20. 承辦人

24. 「使用種類與額度由課外活動組填寫」註記

* 範本類型

* 使用情境
* 使用說明

## 二十一、優先級與原因

優先級：最高

原因：

1. 活動申請表是社團活動送交學校審核與行政流程的核心文件。
2. 本範本直接對應臺北市立大學社團活動申請表。
3. A4 橫式一頁是此表單的關鍵版面條件。
4. 一頁固定版面能減少社團填表時的排版錯誤。
5. 社團可填欄位與學校行政欄位明確分離，可避免誤填。
6. 勾選框、經費合計與長文字限制能改善原表單難填、易跑版的問題。
7. 本範本可與活動企畫書、簽到表、成果報告形成完整活動文件流程。
