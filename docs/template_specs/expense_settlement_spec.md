# ODFlow 範本規格書：經費收支結算表

## 一、範本基本資料

範本名稱：經費收支結算表
常見別名：經費收支表、活動經費結算表、社團活動經費收支結算表、經費結算表
template key：expense_settlement
格式：ODS
分類：財務與清冊型
重要性：最高
是否保留：保留，核心範本
是否支援空白範本下載：支援
是否支援使用此範本建立文件：支援

本範本以臺北市立大學社團活動經費收支結算表格式為基準，用於協助學生社團在活動結束後整理預算通過金額、實際支出金額、學校補助核銷金額與得補助金額上限，作為活動結案、核銷、社團評鑑、行政留存與財務佐證使用。

本範本 v1 的核心原則是：

1. 以學校既有經費收支結算表格式為主。
2. 本範本使用 ODS，不使用 ODT。
3. 外觀接近學校原始表格。
4. 保留原表核心欄位：項目、預算通過金額、實際支出金額、備註。
5. 支援公式自動計算。
6. 支援經費項目動態新增。
7. 備註欄可承擔經費來源功能，但不額外新增學校原表沒有的欄位。
8. 學校補助核銷金額總計與得補助金額上限應自動計算。
9. 課外組承辦人、組長、學務長等行政簽核欄位保留空白。
10. 預留未來與活動企畫書、活動申請表、核銷明細表與活動專案串接的資料接口。
11. 文件打開後應像正式經費收支結算表，而不是範本說明頁。

---

## 二、範本定位

經費收支結算表不是一般流水帳。

本範本的目的不是記錄每一天的現金進出，而是整理活動結束後的財務結算狀況。

本表主要回答以下問題：

1. 活動原本通過多少預算？
2. 活動最後實際支出了多少？
3. 哪些項目屬於學校補助？
4. 哪些項目屬於校外補助、社團會費或自籌？
5. 學校補助可核銷金額是多少？
6. 若實際支出低於原通過預算，補助上限應如何按比例調整？
7. 活動承辦人與學校行政單位是否已確認？

---

## 三、與其他範本的關係

本範本應與以下範本形成活動財務流程：

1. 活動企畫書
   提供活動預算表、預算來源與預估金額。

2. 活動申請表
   提供活動費申請補助、自籌經費與活動基本資料。

3. 活動成果報告
   活動成果報告中不放完整經費表，經費收支結算表另附。

4. 核銷明細表
   未來可提供發票、收據、單據編號、核銷狀態與實際支付資料。

5. 經費收支結算表
   本範本用於活動結束後，彙整預算通過金額、實際支出金額與補助核銷結果。

## 十、公式與計算邏輯

本範本最重要的功能是公式正確。

原表中「A × B / C」的概念應改用明確變數名稱描述，避免與表格欄位 B、C 混淆。

---

### 1. 核心變數定義

系統應定義以下變數：

#### 預算通過總額

定義：

所有經費項目的「預算通過金額」總和。

公式概念：

預算通過總額 = SUM(預算通過金額)

---

#### 實際支出總額

定義：

所有經費項目的「實際支出金額」總和。

公式概念：

實際支出總額 = SUM(實際支出金額)

---

#### 學校補助通過金額

定義：

備註為「學校補助」的經費項目，其「預算通過金額」總和。

公式概念：

學校補助通過金額 = SUMIF(備註 = 學校補助, 預算通過金額)

此數值可視為原表 A × B / C 公式中的 A。

也就是：

A = 原本通過可由學校補助核銷的金額

---

#### 學校補助實際支出金額

定義：

備註為「學校補助」的經費項目，其「實際支出金額」總和。

公式概念：

學校補助實際支出金額 = SUMIF(備註 = 學校補助, 實際支出金額)

---

#### 實際執行比例

定義：

實際支出總額除以預算通過總額。

公式概念：

實際執行比例 = 實際支出總額 / 預算通過總額

此數值對應原表 A × B / C 中的 B / C。

其中：

* B = 實際支出總額
* C = 預算通過總額
* B / C = 實際執行比例

若預算通過總額為 0，實際執行比例應視為 0，避免除以 0 錯誤。

---

### 2. A × B / C 的意義

原表的「得補助金額上限：A × B / C」可理解為：

原本通過可補助的金額 × 實際支出總額 / 預算通過總額

也就是：

學校補助通過金額 × 實際執行比例

用途：

當活動最後實際支出低於原本通過預算時，學校補助金額應依實際執行比例折減。

範例：

若原本通過預算總額為 10,000 元，原本學校補助通過金額為 5,000 元，最後實際支出總額為 8,000 元：

實際執行比例 = 8,000 / 10,000 = 80%

得補助金額上限 = 5,000 × 80% = 4,000

---

### 3. 保守補助上限公式

為避免補助金額超過合理範圍，ODFlow v1 應使用保守公式。

得補助金額上限應取以下三者的最小值：

1. 學校補助通過金額
2. 學校補助實際支出金額
3. 學校補助通過金額 × 實際執行比例

公式概念：

得補助金額上限 = MIN(
學校補助通過金額,
學校補助實際支出金額,
學校補助通過金額 × 實際執行比例
)

原因：

1. 不得超過原本通過可由學校補助的金額。
2. 不得超過實際屬於學校補助項目的支出金額。
3. 若活動實際支出低於預算通過總額，應按實際執行比例折減。
4. 若活動實際支出高於預算通過總額，也不得因此放大補助金額。

---

### 4. 學校補助核銷金額總計

學校補助核銷金額總計應自動計算。

建議定義：

學校補助核銷金額總計 = 得補助金額上限

也就是使用保守補助上限公式計算出的結果。

原因：

1. 原表將「學校補助核銷金額總計」與「得補助金額上限」放在同一結算區。
2. 學校補助核銷金額不應高於得補助金額上限。
3. 若使用者需要實際核定金額，學校行政人員仍可於後續審核時調整。
4. ODFlow 應先提供一個安全、合理、可解釋的計算結果。

---

### 5. 建議 ODS 公式

以下公式以明細列第 8 列至第 17 列為例。

假設：

* A 欄：項目
* B 欄：預算通過金額
* C 欄：實際支出金額
* D 欄：備註

#### 預算通過總額

```ods
=SUM(B8:B17)
```

#### 實際支出總額

```ods
=SUM(C8:C17)
```

#### 學校補助通過金額

```ods
=SUMIF(D8:D17;"學校補助";B8:B17)
```

#### 學校補助實際支出金額

```ods
=SUMIF(D8:D17;"學校補助";C8:C17)
```

#### 實際執行比例

```ods
=IF(SUM(B8:B17)=0;0;SUM(C8:C17)/SUM(B8:B17))
```

#### 得補助金額上限

```ods
=IF(SUM(B8:B17)=0;0;MIN(SUMIF(D8:D17;"學校補助";B8:B17);SUMIF(D8:D17;"學校補助";C8:C17);SUMIF(D8:D17;"學校補助";B8:B17)*(SUM(C8:C17)/SUM(B8:B17))))
```

說明：

ODS 公式使用分號作為函數參數分隔符。若匯出為 XLSX，系統可視格式轉換為逗號分隔公式。

## 十一、結算公式區

結算公式區應清楚呈現主要結果。

建議保留接近學校原表的顯示方式：

| 項目                |  預算通過金額 | 實際支出金額 | 備註                |
| ----------------- | ------: | -----: | ----------------- |
| 支出金額總計            |  預算通過總額 | 實際支出總額 | B：實際支出金額；C：預算通過金額 |
| 學校補助核銷金額總計        | 得補助金額上限 |        | A：學校補助通過金額        |
| 得補助金額上限：A × B / C | 得補助金額上限 |        | 應以申請金額為上限         |

但為避免 B、C 與表格欄位混淆，ODFlow 內部不應使用 B、C 作為變數名稱。

內部應使用：

* approved_budget_total
* actual_expense_total
* approved_school_subsidy
* school_subsidy_actual_expense
* execution_ratio
* subsidy_cap

## 十二、補助公式備註文字

ODS 表格可保留原表概念，但建議文字改得更清楚。

建議顯示：

```text
得補助金額上限：A × B / C
A：學校補助通過金額
B：實際支出總額
C：預算通過總額
應以申請金額為上限
```

避免使用：

```text
B：實際支出金額      C：預算通過金額
A：預算通過-學校補助核銷金額總計
```

原因：

1. 原備註容易與 B 欄、C 欄混淆。
2. A 的定義不夠清楚。
3. 重新定義後較容易讓使用者理解，也較不容易讓系統算錯。

## 十四、資料驗證與防呆

本範本應具備基本防呆。

### 1. 金額欄位

預算通過金額與實際支出金額應限制為數字。

建議：

* 不允許文字。
* 不允許負數。
* 空白視為 0。
* 金額格式使用千分位。
* 單位為元。

---

### 2. 備註欄下拉選單

備註欄建議提供下拉選單。

選項：

* 學校補助
* 校外補助
* 社團會費
* 自籌
* 其他

規則：

1. 使用者可選擇選項。
2. 若需補充說明，可手動輸入文字。
3. 只有明確為「學校補助」的列，才納入學校補助公式。
4. 若備註為「學校補助-文宣」或其他延伸文字，v1 不建議自動納入，避免誤判。
5. 未來可支援包含關鍵字的判斷，但 v1 優先使用精準匹配。

---

### 3. 除以 0 防呆

若預算通過總額為 0：

* 實際執行比例顯示 0。
* 得補助金額上限顯示 0。
* 不得出現 #DIV/0! 錯誤。

---

### 4. 補助超額防呆

得補助金額上限不得超過：

1. 學校補助通過金額。
2. 學校補助實際支出金額。
3. 依實際執行比例調整後的補助金額。

因此公式應使用 MIN。

## 二十二、優先級與原因

優先級：最高

原因：

1. 經費收支結算表是活動結案與核銷的核心財務文件。
2. 本範本直接對應臺北市立大學社團活動經費收支結算表。
3. 經費結算涉及金額與公式，必須使用 ODS 處理。
4. 自動計算可降低社團手算錯誤。
5. 補助上限公式若不明確，容易造成核銷金額錯誤。
6. 使用明確變數取代原表 A、B、C 模糊備註，可降低實作錯誤。
7. 本範本可與活動企畫書、活動申請表、成果報告、核銷明細表形成完整活動財務流程。
