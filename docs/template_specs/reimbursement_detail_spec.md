# ODFlow 範本規格書：核銷明細表

## 一、範本基本資料

範本名稱：核銷明細表
常見別名：單據明細表、支出明細表、收據明細表、活動核銷明細表、財務憑證明細表
template key：reimbursement_detail
格式：ODS
分類：財務與清冊型
重要性：高
是否保留：保留，核心輔助範本
是否支援空白範本下載：支援
是否支援使用此範本建立文件：支援

本範本為 ODFlow 自訂的社團財務輔助表，用於整理活動或社團運作中的每一筆支出、單據、憑證、墊付款人、經費來源與核銷狀態。

本範本不是學校課外活動組既有制式表單，而是 ODFlow 為了補足社團財務管理、核銷準備、評鑑佐證與專案資料整理所設計的內部實用表格。

本範本 v1 的核心原則是：

1. 使用 ODS，不使用 ODT。
2. 以每一張發票、收據或憑證為一筆資料。
3. 支援金額自動加總。
4. 支援依經費來源分類統計。
5. 支援對應經費收支結算表的經費項目。
6. 支援記錄單據號碼、付款方式、墊付款人與憑證狀態。
7. 預留未來上傳單據照片或附件的資料接口。
8. 可作為經費收支結算表的實際支出資料來源。
9. 可作為評鑑資料整理與財務佐證使用。
10. 文件打開後應像正式財務明細表，而不是範本說明頁。

---

## 二、範本定位

核銷明細表與經費收支結算表不同。

### 1. 經費收支結算表

經費收支結算表是活動結束後的總結表。

重點是：

* 預算通過金額
* 實際支出金額
* 學校補助核銷金額
* 得補助金額上限
* 結算公式

### 2. 核銷明細表

核銷明細表是每一張單據、每一筆支出的整理表。

重點是：

* 哪一天支出
* 買了什麼
* 花了多少
* 哪個店家或廠商
* 用哪一種單據
* 單據號碼是什麼
* 誰先墊錢
* 經費來源是什麼
* 憑證是否已附
* 這筆支出是否可核銷

### 3. 兩者關係

核銷明細表可作為經費收支結算表的資料來源。

未來流程方向：

核銷明細表 → 彙整各項實際支出 → 經費收支結算表

## 四、工作表設定

本範本 v1 建議使用單一工作表。

工作表名稱：

核銷明細表

### 1. 檔案格式

格式：

ODS

原因：

1. 本表需要金額加總。
2. 本表需要資料篩選。
3. 本表需要下拉選單。
4. 本表未來可與經費收支結算表串接。
5. 本表需要處理多筆支出明細，使用 ODS 比 ODT 更合理。

### 2. 頁面設定

建議設定：

* 紙張：A4
* 方向：橫式
* 可列印
* 可依明細筆數自然延伸
* 主要字型：標楷體或系統可用中文字型
* 表頭列固定
* 金額欄位使用千分位格式
* 可啟用篩選功能

## 六、活動基本資料區

活動基本資料區用於辨識本核銷明細表對應哪一個活動或專案。

欄位包含：

* 活動名稱
* 活動日期
* 主辦社團
* 活動負責人
* 財務負責人
* 製表日期

### 1. 活動名稱

來源：

* 可由使用者手填。
* 未來可從 ODFlow 活動專案、活動企畫書或活動申請表帶入。

### 2. 活動日期

來源：

* 可由使用者手填。
* 未來可從活動申請表或活動專案帶入。

### 3. 主辦社團

來源：

* 可由使用者手填。
* 未來可從活動專案資料帶入。

### 4. 活動負責人

用途：

記錄活動主要承辦人。

### 5. 財務負責人

用途：

記錄實際整理單據與經費的人。

### 6. 製表日期

來源：

* 可由系統預設為今日。
* 使用者應可修改。

## 八、欄位定義

### 1. 序號

欄位名稱：

序號

用途：

自動編號每一筆核銷明細。

規則：

1. 從 1 開始。
2. 可由公式自動產生。
3. 若使用者刪除列，序號可重新計算。
4. 不應由使用者手動亂填。

---

### 2. 支出日期

欄位名稱：

支出日期

用途：

記錄實際支出或消費日期。

格式：

YYYY/MM/DD

規則：

1. 應為日期格式。
2. 若單據日期與實際付款日期不同，優先填單據日期。
3. 付款日期可放備註。

---

### 3. 對應經費項目

欄位名稱：

對應經費項目

用途：

對應經費收支結算表中的「項目」。

範例：

* 場地費
* 講師費
* 文宣費
* 保險費
* 餐費
* 交通費
* 器材租借費
* 印刷費
* 雜支

規則：

1. v1 可由使用者手填。
2. 建議提供下拉選單。
3. 未來可從活動企畫書預算表或經費收支結算表的項目自動帶入。
4. 此欄是未來彙整實際支出到經費收支結算表的關鍵欄位。

---

### 4. 品名／用途

欄位名稱：

品名／用途

用途：

說明這筆支出實際買了什麼或用在哪裡。

範例：

* 海報印刷
* 講師鐘點費
* 工作人員餐費
* 活動保險
* 場地租借
* 文具用品
* 捷運交通費

規則：

1. 應簡短明確。
2. 不宜只寫「雜支」。
3. 若內容較多，可在備註補充。

---

### 5. 店家／受款單位

欄位名稱：

店家／受款單位

用途：

記錄付款對象。

範例：

* 全家便利商店
* 影印店
* 講師姓名
* 保險公司
* 場地單位
* 網路購物平台

規則：

1. 若為個人收款，可填姓名。
2. 若為網路購物，可填平台或賣家名稱。
3. 若無法確認，可留白或填「未記錄」。

---

### 6. 單據類型

欄位名稱：

單據類型

用途：

記錄憑證種類。

建議下拉選項：

* 發票
* 電子發票證明聯
* 收據
* 免用統一發票收據
* 匯款證明
* 付款截圖
* 領據
* 其他

規則：

1. 使用者應選擇最接近的單據類型。
2. 若學校不接受某些憑證，仍可保留作為社團內部紀錄。
3. 是否可正式核銷應依學校行政規定判斷。

---

### 7. 單據號碼

欄位名稱：

單據號碼

用途：

記錄發票號碼、收據編號或其他憑證編號。

規則：

1. 若是發票，填發票號碼。
2. 若是收據，填收據編號。
3. 若無編號，可留白。
4. 若為付款截圖，可填交易序號或訂單編號。

---

### 8. 經費來源

欄位名稱：

經費來源

用途：

標示此筆支出預計由哪一種經費來源負擔。

建議下拉選項：

* 學校補助
* 校外補助
* 社團會費
* 自籌
* 其他

規則：

1. 此欄應與經費收支結算表的備註欄邏輯一致。
2. 若經費來源為「學校補助」，未來可彙整到經費收支結算表的學校補助實際支出。
3. 若經費來源不是學校補助，則不納入學校補助核銷公式。
4. v1 優先使用精準分類，不使用模糊關鍵字判斷。

---

### 9. 支付方式

欄位名稱：

支付方式

用途：

記錄付款方式。

建議下拉選項：

* 現金
* 轉帳
* 信用卡
* 金融卡
* 行動支付
* 匯款
* 其他

規則：

1. 用於日後確認款項流向。
2. 若由社員先墊付，應同步填寫墊付款人。

---

### 10. 墊付款人

欄位名稱：

墊付款人

用途：

記錄誰先幫社團墊錢。

規則：

1. 若由社團帳戶直接支付，可填「社團帳戶」。
2. 若由個人代墊，填代墊者姓名。
3. 此欄有助於後續還款與內部對帳。

---

### 11. 金額

欄位名稱：

金額

用途：

記錄此筆支出金額。

格式：

金額，整數，元。

規則：

1. 應為數字。
2. 不允許負數。
3. 空白視為 0。
4. 使用千分位格式。
5. 此欄應納入總金額加總。

---

### 12. 憑證狀態

欄位名稱：

憑證狀態

用途：

追蹤單據是否齊全。

建議下拉選項：

* 已附
* 待補
* 遺失
* 不核銷
* 不適用

規則：

1. 若要正式核銷，應盡量為「已附」。
2. 若為「待補」，統計摘要應提示仍有待補憑證。
3. 若為「遺失」，應可在備註說明原因。
4. 若為「不核銷」，仍可保留作為社團內部支出紀錄。

---

### 13. 附件檔名／連結

欄位名稱：

附件檔名／連結

用途：

記錄收據照片、發票掃描檔、付款截圖或其他憑證檔案。

規則：

1. v1 可填檔名或連結。
2. 未來可由 ODFlow 上傳附件後自動產生檔名或檔案路徑。
3. 空白 ODS 不應內嵌大量圖片，避免檔案過大。
4. 若需要收據圖片排版，未來可另做「收據黏貼單」或附件 ZIP。

---

### 14. 備註

欄位名稱：

備註

用途：

補充說明特殊情況。

範例：

* 單據遺失，已請店家補開
* 與另一筆支出合併付款
* 網購訂單，發票另寄
* 此筆不申請學校補助，僅社團內部紀錄
* 實際用途與品名不同

## 十、公式與計算邏輯

以下公式以明細列第 8 列至第 107 列為例。

假設：

* H 欄：經費來源
* K 欄：金額
* L 欄：憑證狀態

### 1. 支出總金額

```ods
=SUM(K8:K107)
```

### 2. 學校補助支出總金額

```ods
=SUMIF(H8:H107;"學校補助";K8:K107)
```

### 3. 校外補助支出總金額

```ods
=SUMIF(H8:H107;"校外補助";K8:K107)
```

### 4. 社團會費支出總金額

```ods
=SUMIF(H8:H107;"社團會費";K8:K107)
```

### 5. 自籌支出總金額

```ods
=SUMIF(H8:H107;"自籌";K8:K107)
```

### 6. 其他支出總金額

```ods
=SUMIF(H8:H107;"其他";K8:K107)
```

### 7. 已附憑證筆數

```ods
=COUNTIF(L8:L107;"已附")
```

### 8. 待補憑證筆數

```ods
=COUNTIF(L8:L107;"待補")
```

### 9. 遺失憑證筆數

```ods
=COUNTIF(L8:L107;"遺失")
```

### 10. 不核銷筆數

```ods
=COUNTIF(L8:L107;"不核銷")
```

說明：

ODS 公式使用分號作為函數參數分隔符。若匯出為 XLSX，系統可視格式轉換為逗號分隔公式。

## 十二、空白範本下載要求

下載的空白 ODS 應是正式核銷明細表版型。

空白範本應至少包含：

1. 文件標題
2. 活動基本資料區
3. 核銷明細表格區
4. 統計摘要區
5. 備註區
6. 下拉選單設定
7. 可運作公式

空白範本建議預留：

100 筆核銷明細列

原因：

1. 多數社團活動支出筆數不會超過 100 筆。
2. 預留 100 列可避免一般使用者自行插入列破壞公式。
3. 若未來資料更多，生成文件頁可動態產生更多列。

空白 ODS 不應內嵌收據圖片，避免檔案過大與版面不穩。

## 十四、與經費收支結算表的串接

核銷明細表應能成為經費收支結算表的資料來源。

未來可依「對應經費項目」彙整：

* 每個經費項目的實際支出金額
* 每個經費來源的實際支出金額
* 學校補助實際支出金額
* 自籌支出金額
* 校外補助支出金額

串接邏輯：

1. 核銷明細表依「對應經費項目」分組。
2. 加總各項目的「金額」。
3. 將結果帶入經費收支結算表的「實際支出金額」欄。
4. 若經費來源為「學校補助」，同步帶入學校補助相關公式。
5. 經費收支結算表再計算補助上限與核銷金額。

## 二十一、優先級與原因

優先級：高

原因：

1. 學校雖未提供制式核銷明細表，但社團實務上非常需要。
2. 核銷明細表可補足經費收支結算表缺少單據明細的問題。
3. 本範本可降低社團財務對帳、核銷與評鑑整理成本。
4. 本範本可追蹤待補、遺失或不核銷憑證。
5. 本範本可與經費收支結算表、收據附件、評鑑 ZIP 形成完整財務資料鏈。
6. 使用 ODS 可支援公式、篩選、下拉選單與後續自動化。
