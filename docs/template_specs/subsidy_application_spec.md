# ODFlow 範本規格書：補助申請表

## 一、範本基本資料

範本名稱：補助申請表
常見別名：活動補助申請表、社團補助申請表、經費補助申請表、補助申請書、活動經費補助申請書
template key：subsidy_application
格式：ODT
分類：財務與清冊型
重要性：高
是否保留：保留，核心範本
是否支援空白範本下載：支援
是否支援使用此範本建立文件：支援

本範本用於學生社團在申請活動經費、社團補助、校內補助、校外補助或專案補助時，整理申請單位、活動資訊、補助目的、經費需求、申請補助金額、自籌金額、預期效益、附件清單與簽核欄位。

本範本 v1 的核心原則是：

1. 使用 ODT，不使用 ODS。
2. 補助申請表是正式申請文件，不是記帳表。
3. 詳細預算計算由經費預算表處理。
4. 補助申請表只呈現申請重點與金額摘要。
5. 若學校或補助單位有指定表單，應以指定表單為準。
6. ODFlow 的補助申請表應作為通用版、草稿版或社團內部整理版。
7. 可從活動企畫書、活動申請表、經費預算表帶入資料。
8. 文件打開後應像正式補助申請表，而不是範本說明頁。

---

## 二、範本定位

補助申請表是社團向校內或校外單位申請經費支持的正式文件。

它主要回答以下問題：

1. 誰要申請補助？
2. 申請哪一個活動或專案？
3. 活動為什麼需要補助？
4. 補助金額是多少？
5. 自籌金額是多少？
6. 補助款預計用在哪些項目？
7. 活動對學生、社團、學校或社會有什麼效益？
8. 需要附上哪些附件？
9. 申請單位與承辦人是誰？

---

## 三、與其他範本的區別

### 1. 與活動企畫書的關係

活動企畫書說明活動整體規劃。

補助申請表只整理補助申請重點。

可從活動企畫書帶入：

* 活動名稱
* 活動宗旨
* 活動內容
* 活動時間
* 活動地點
* 活動對象
* 預期效益
* 主辦單位
* 協辦單位

---

### 2. 與活動申請表的關係

活動申請表是向學校申請辦理活動的行政表單。

補助申請表是向補助單位申請經費的表單。

兩者可互相串接，但不應混成同一份文件。

---

### 3. 與經費預算表的關係

經費預算表負責詳細計算。

補助申請表只放摘要。

可從經費預算表帶入：

* 活動總預算
* 申請補助金額
* 自籌金額
* 自籌比例
* 主要經費項目
* 預算明細附件

---

### 4. 與經費收支結算表的關係

補助申請表是活動前申請補助。

經費收支結算表是活動後結算補助使用情形。

未來流程：

補助申請表 → 活動執行 → 經費收支結算表

---

### 5. 與核銷明細表的關係

核銷明細表是活動後整理發票、收據與憑證。

補助申請表不處理單據細節，只列出預計使用經費方向。

---

## 四、適用情境

本範本可用於：

1. 校內社團活動補助申請。
2. 學生會或學生議會補助申請。
3. 課外活動組活動補助申請。
4. 青年局、教育局、文化局等外部補助申請草稿。
5. 社團向合作單位申請經費支持。
6. 社團內部整理補助申請資料。

注意：

若補助單位有指定格式，應使用補助單位官方格式。
ODFlow 補助申請表可作為填寫官方格式前的整理文件，也可作為沒有固定格式時的正式申請文件。

正式文件標題建議為：

臺北市立大學

若不是單一活動，可使用：

臺北市立大學

或：

臺北市立大學
{{club_name}} {{project_name}}補助申請表

## 十、補助申請說明

此區是補助申請表的核心。

建議包含：

1. 申請補助原因
2. 活動目的
3. 活動內容摘要
4. 補助必要性

---

### 1. 申請補助原因

用途：

說明為什麼需要申請補助。

範例：

* 本活動需購置活動材料、保險與餐食，超出社團現有經費負擔。
* 本活動服務對象包含校外民眾與學生，具有公共性與公益性。
* 本活動為年度重點活動，需補助支持以提升活動品質。
* 本活動預計增加新生參與，協助社團穩定發展。

---

### 2. 活動目的

用途：

簡要說明活動要達成的目的。

可從活動企畫書的活動宗旨帶入，但不應整篇複製過長內容。

---

### 3. 活動內容摘要

用途：

簡要說明活動會做什麼。

建議控制在 100 至 200 字內。

若活動內容較複雜，詳細內容應放在活動企畫書附件。

---

### 4. 補助必要性

用途：

說明補助款對活動完成的重要性。

範例：

* 若獲補助，可降低參與者負擔，提高學生參與意願。
* 若獲補助，可補足保險、材料與交通等必要支出。
* 若未獲補助，活動規模與服務人數將需要縮減。
* 補助款將用於活動必要支出，不作為非活動用途。

---

## 十一、經費需求摘要

此區用於整理補助申請金額。

詳細項目應由經費預算表處理，補助申請表只呈現摘要。

建議欄位：

* 活動總經費
* 申請補助金額
* 自籌金額
* 其他補助金額
* 自籌比例
* 經費預算表附件

### 1. 活動總經費

來源：

經費預算表自動計算或使用者手填。

---

### 2. 申請補助金額

來源：

經費預算表的申請補助總額。

規則：

1. 不應大於活動總經費。
2. 若補助單位有上限，應在備註說明。
3. 若補助單位要求自籌比例，應同步顯示自籌金額與比例。

---

### 3. 自籌金額

來源：

經費預算表的自籌總額。

自籌來源可能包含：

* 社團會費
* 活動收入
* 自行募款
* 合作單位支持
* 其他

---

### 4. 其他補助金額

用途：

若同一活動另有其他補助來源，應列出避免重複申請。

---

### 5. 自籌比例

公式概念：

自籌比例 = 自籌金額 / 活動總經費

若活動總經費為 0，應顯示 0，不得出現除以 0 錯誤。

---

## 十三、補助款使用規劃

此區用於簡要說明補助款會用在哪些項目。

建議表格：

| 項目類別 | 項目 | 預計金額 | 說明 |
| ---- | -- | ---: | -- |

範例：

| 項目類別 | 項目     | 預計金額 | 說明         |
| ---- | ------ | ---: | ---------- |
| 保險費  | 活動保險   | 1200 | 保障活動參與者安全  |
| 材料費  | 活動材料   | 3000 | 工作坊實作使用    |
| 餐食費  | 工作人員餐費 | 2000 | 活動當日工作人員餐食 |
| 印刷費  | 海報與講義  | 1500 | 宣傳與課程使用    |

規則：

1. 此表不需要列出全部細項。
2. 完整明細應附經費預算表。
3. 補助款使用規劃應與經費預算表一致。
4. 不應出現與活動無關的支出。

---

## 十四、預期效益

預期效益用於說明補助後能達成的成果。

建議分成：

1. 對參與者效益
2. 對社團效益
3. 對學校或社會效益
4. 可量化成果

---

### 1. 對參與者效益

範例：

* 增加學生參與公共事務與服務活動的機會。
* 提升參與者對活動主題的理解。
* 降低參與者負擔，提高參與意願。
* 提供學生實作與交流機會。

---

### 2. 對社團效益

範例：

* 提升社團活動品質。
* 培養幹部企畫、執行與財務管理能力。
* 增加社員參與度。
* 強化社團年度重點活動成果。

---

### 3. 對學校或社會效益

範例：

* 提升學校學生社團公共參與形象。
* 促進校內外交流。
* 回應社區或服務對象需求。
* 增加學校社團活動能見度。

---

### 4. 可量化成果

建議表格：

| 成果指標   | 預計目標                             |
| ------ | -------------------------------- |
| 預計參與人數 | {{expected_participant_count}} 人 |
| 預計服務人次 | {{expected_service_count}} 人次    |
| 預計辦理場次 | {{event_session_count}} 場        |
| 預計產出成果 | {{expected_outputs}}             |

可量化成果可依活動性質調整。

---

## 十五、附件清單

附件是補助申請表的重要區塊。

附件不得只寫「附件一、附件二、附件三」，應寫出具體名稱。

建議附件：

1. 活動企畫書
2. 經費預算表
3. 活動申請表
4. 社團年度計畫
5. 活動流程表
6. 工作分配表
7. 場地申請證明
8. 報價單
9. 合作單位證明
10. 其他補助單位要求文件

建議格式：

* 附件一：臺北市立大學傑青社「期初社員大會」活動企畫書
* 附件二：臺北市立大學傑青社「期初社員大會」經費預算表
* 附件三：活動場地申請證明
* 附件四：講師邀請資料
* 附件五：報價單

若無附件，應填：

附件：無

## 十七、審核欄位

若作為校內通用申請表，可保留審核欄位。

建議欄位：

* 承辦人
* 單位主管
* 核定補助金額
* 審核結果
* 審核意見

建議表格：

| 審核項目   | 內容              |
| ------ | --------------- |
| 承辦人    |                 |
| 單位主管   |                 |
| 核定補助金額 |                 |
| 審核結果   | □ 通過　□ 補件　□ 不通過 |
| 審核意見   |                 |

規則：

1. 社團填寫時，審核欄位應保留空白。
2. 若補助單位不需要審核欄位，可刪除或留白。
3. 空白 ODT 本體不應出現系統說明文字。

## 十八、備註

備註區用於放置補充說明。

範例：

* 本申請表所列金額依經費預算表計算。
* 實際補助金額依審核結果為準。
* 活動辦理後將依規定提交成果報告與經費收支結算表。
* 若補助款未核准，活動規模將依社團經費狀況調整。
* 本活動相關單據將於活動結束後整理核銷。

若無備註，可填「無」。

## 二十二、申請狀態

雖然正式 ODT 本體不一定需要顯示申請狀態，但 ODFlow 專案層應保留申請狀態。

建議狀態：

* 草稿
* 待送出
* 已送出
* 補件中
* 已核准
* 未核准
* 已結案

用途：

1. 追蹤補助申請進度。
2. 串接補助審核結果。
3. 提醒後續成果報告與經費結算。

正式空白 ODT 本體不應出現「草稿、待送出、已送出」等系統流程欄位，除非使用者在生成文件時選擇輸出。

## 二十九、優先級與原因

優先級：高

原因：

1. 補助申請表是活動經費規劃與行政申請的重要文件。
2. 本範本可將活動企畫書、活動申請表與經費預算表串接成補助申請資料。
3. 本範本可協助社團清楚說明申請補助原因、經費需求與預期效益。
4. 本範本可避免補助申請只剩金額，缺少活動價值與補助必要性說明。
5. 本範本可作為後續經費收支結算表、活動成果報告與評鑑資料的前置資料。
6. 本範本可支援校內與校外補助申請草稿整理。
