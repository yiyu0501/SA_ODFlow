# ODFlow 3 分鐘展示腳本

## 1. 開場：ODFlow 解決什麼問題

開場可先說：

> 學生社團平常文件很分散，到了評鑑前才開始臨時整理 PDF，常常找不到原始檔、分類混亂，也不知道哪些資料還缺。ODFlow 要解決的是平時就把 ODF 原始檔保存好，評鑑前再一鍵整理成 PDF 評鑑上傳包。

## 2. 建立或確認社團基本資料

進入「社團設定」頁，說明：

- 這裡可以設定學年度、校區、社團名稱
- 這些資料會被「社團評鑑」匯出的 ZIP 命名直接使用
- 若沒有設定，系統會先使用示範預設值

## 3. 建立示範資料

點擊「建立示範資料」，說明：

- 系統會建立幹部會議紀錄、社員大會紀錄、活動檢討會紀錄、年度計畫、活動成果報告
- 狀態會混合正式版、已歸檔、草稿
- 這些資料可以直接讓「儀表板」與「社團評鑑」顯示社團評鑑資料完整度與缺漏

## 4. 在空白範本下載 ODT / ODS 範本

切到「空白範本」頁：

- 說明目前支援 22 個 ODT / ODS 範本
- 四大類分別是日常行政、活動專案、社團評鑑、財務與清冊
- 點擊任一範本的下載空白範本
- 可特別展示「會議紀錄」「開會通知單」或「活動企劃書」，說明這三個核心範本已改為 ODT placeholder 樣板
- 說明這是降低學生從 Word / Excel 轉向 ODF 門檻的入口

## 5. 用生成文件產生一份會議紀錄

切到「生成文件」頁：

- 輸入會議日期、會議名稱、會議類型
- 貼上一段逐字稿或會議摘要
- 點擊產生會議紀錄草稿
- 說明目前是 mock parser，尚未串 OpenAI API，但流程完整，後續可替換成真正 AI parser

## 6. 在檔案庫匯出 ODT / PDF

切到「檔案庫」頁：

- 查看剛產生的文件
- 展示版本管理與狀態切換
- 點擊產生 / 更新 ODT
- 點擊產生 / 更新 PDF
- 展示會議紀錄或活動企劃書的正式標題、基本資料表與章節分段
- 說明三個核心 ODT 會優先使用固定樣板填入，失敗時才回到 generator 版本
- 說明平時保存的是 ODF 原始檔，對外評鑑上傳則使用 PDF

## 7. 在儀表板看社團評鑑資料完整度

切到「儀表板」頁：

- 展示整體社團評鑑資料完整度
- 說明七大評鑑項目完成率
- 指出哪些文件是已完成、哪些仍在進行中
- 顯示缺漏文件提醒與下一步建議

## 8. 在社團評鑑匯出 PDF 評鑑上傳包與 ODF 原始檔備份 ZIP

切到「社團評鑑」頁：

- 說明這裡會根據七大評鑑分類做檢核
- 先產生 PDF 評鑑上傳包
- 再產生 ODF 原始檔備份包
- 展示 ZIP 檔名會帶入學年度、校區、社團名稱
- 補一句：目前是本機 ZIP 下載，不是雲端自動上傳

## 9. 收尾：說明 ODF 原始檔備份價值

收尾可說：

> 多數社團最後只會留下 PDF，但 PDF 不適合持續維護。ODFlow 的重點是把 ODF 原始檔保存納入平時流程，讓社團文件不是只為了評鑑一次，而是可以持續被編修、延續和交接。
